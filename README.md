> **把真实问题做成能长期运行的产品。**

你好，我是 **Duke Yeah**，一名独立开发者与产品工程师。

我喜欢从一个具体的工作流出发，独立完成需求梳理、交互设计、工程实现、部署维护和持续迭代。比起只做一个能演示的 Demo，我更在意软件是否真的好用、是否能稳定运行，以及它能不能减少人的重复劳动。
